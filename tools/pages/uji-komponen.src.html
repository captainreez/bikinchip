Rumus (MathML) dan penjelasan berlapis

Tegangan kapasitor pada rangkaian RC yang diberi tegangan step:

vC(t)=VS⁢(1−e−t/RC)v_C(t) = V_S · (1 − e^(−t/RC))

Kapasitor seperti ember yang diisi lewat selang sempit. Awalnya air mengalir deras, lalu makin lambat karena ember hampir penuh. Konstanta waktu menyatakan seberapa lama pengisian itu.

Setelah satu τ = RC tegangan mencapai 63.2% nilai akhir; setelah 4.6τ mencapai 99%. Rise time 10% ke 90% adalah 2.2τ.

Pada interconnect nyata R dan C tersebar sepanjang kawat. Delay 50% kawat RC tersebar mendekati 0.38·R·C, bukan 0.69·R·C seperti model satu R satu C; inilah dasar model Elmore dan penyisipan repeater.

Grafik dari persamaan model

Rangkaian RC: transien dan respons frekuensi

Model: satu resistor dan satu kapasitor ideal, sumber step 1 V dengan resistansi sumber nol. Tidak ada induktansi maupun kebocoran.

Jika R digandakan dan C tetap, apa yang terjadi pada frekuensi cutoff?

  • Naik dua kali
  • Turun menjadi setengah
  • Tetap
  • Turun menjadi seperempat

fc = 1/(2πRC). R berada di penyebut dengan pangkat satu, jadi menggandakan R membagi dua fc. Kurva Bode bergeser ke kiri satu oktaf, dan kurva transien menjadi dua kali lebih lambat.

Waveform: pelanggaran setup dan hold

Flip-flop D: kapan data boleh berubah

Model: tepi naik clock di t = 4 dan t = 8; setup 0.6, hold 0.3, clock-to-Q 0.4 satuan waktu. Pada pelanggaran, Q digambar X sampai tepi berikutnya. Flip-flop nyata akan mengendap ke 0 atau 1 setelah waktu acak (metastability, dibahas di M09).

Counter 3 bit dengan enable

Penyorot sintaks

// Counter 3 bit dengan enable dan reset sinkron
module counter #(parameter int W = 3) (
  input  logic         clk, rst_n, en,
  output logic [W-1:0] q
);
  always_ff @(posedge clk) begin
    if (!rst_n)  q <= '0;
    else if (en) q <= q + 1'b1;
  end
endmodule

# Clock 500 MHz di port clk
create_clock -name clk -period 2.0 [get_ports clk]
set_input_delay 0.4 -clock clk [get_ports en]

import math
def f_cutoff(r, c):
    """Frekuensi cutoff RC dalam Hz."""
    return 1 / (2 * math.pi * r * c)  # 10k, 100p -> 159 kHz

# a0 = a0 + a1, lalu kembali
add_two:
    add  a0, a0, a1
    ret
