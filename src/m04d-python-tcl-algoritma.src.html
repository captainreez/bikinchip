Intuisi dulu

Python: nama adalah stiker, objek adalah kotak

Bayangkan gudang berisi kotak (objek). Variabel bukan kotak; ia stiker bernama yang ditempel pada kotak. b = a menempelkan stiker kedua pada kotak yang sama: mengubah isi kotak terlihat lewat kedua stiker. Menyalin berarti membeli kotak baru dan memindahkan isinya. Di mana analogi ini berhenti: kotak yang isinya kotak lain (list di dalam list) hanya menyimpan stiker-ke-kotak; menyalin kotak luar (salinan dangkal) menyalin stiker itu, bukan kotak dalamnya, sehingga dua kotak luar menunjuk kotak dalam yang sama.

Big-O: mencari nama di buku telepon

Mencari nama dengan membaca halaman demi halaman butuh waktu sebanding jumlah halaman (linear). Membuka di tengah lalu menyempit butuh jumlah langkah sebanding logaritma (pencarian biner, syaratnya terurut). Memakai indeks huruf yang langsung membawa ke halaman yang tepat nyaris konstan (tabel hash). Di mana analogi ini berhenti: "nyaris konstan" bergantung pada indeks yang tersebar merata; bila banyak nama jatuh ke satu huruf, kamu kembali membaca daftar panjang. Big-O juga mengabaikan konstanta: algoritma O(n) dengan konstanta 1000 bisa kalah dari O(n log n) pada n kecil.

Graf: peta kota dan aturan arus air

Netlist seperti peta: persimpangan (gerbang) dihubungkan jalan searah (kabel). Pertanyaan khas: siapa saja yang terpengaruh bila persimpangan ini macet (kerucut fanout, BFS), urutan mana yang aman untuk dihitung (urutan topologis), dan jalur terlama dari masuk ke keluar (jalur kritis). Di mana analogi ini berhenti: peta jalan boleh punya putaran; sirkuit kombinasional tidak boleh (loop kombinasional adalah bug), dan itu yang membuat urutan topologis dan DP sederhana bisa dipakai.

Tcl: juru tulis yang membuka amplop sekali

Tcl memperlakukan setiap baris sebagai amplop berisi kata. Juru tulis (parser) memecah baris menjadi kata, mengganti $var dan [perintah] satu kali, lalu menyerahkan daftar kata hasilnya ke perintah. Kurung kurawal adalah amplop segel: isinya diserahkan apa adanya. Di mana analogi ini berhenti: perintah seperti if, while, dan expr menerima isi segel sebagai skrip atau ekspresi lalu membukanya sendiri; di situlah substitusi kedua terjadi, dan karena itu expr {$a + $b} lebih aman dan lebih cepat daripada expr $a + $b.

Penjelasan formal

4.1 Python: model data dan eksekusi

Setiap nilai di Python adalah objek dengan tiga hal: identitas (alamat di memori, id(x)), tipe, dan nilai. Variabel adalah nama di sebuah ruang nama (namespace) yang menunjuk ke objek; penugasan b = a menyalin referensi, bukan objek. Operator is membandingkan identitas, sedangkan == membandingkan nilai (memanggil __eq__). Objek bertipe mutable (list, dict, set) boleh diubah di tempat; immutable (int, str, tuple, frozenset) tidak, sehingga "mengubah" string selalu membuat string baru.

  • Aliasing dan salinan. b = a membuat alias. a[:], list(a), dan a.copy() membuat salinan dangkal: objek luar baru, elemen sama. copy.deepcopy(a) menyalin rekursif. Visualisasi 1 memperlihatkan ketiganya.
  • Jebakan. Argumen bawaan mutable (def f(x, acc=[])) dibuat sekali saat def dijalankan sehingga dibagi antar panggilan; pakai None sebagai nilai awal. p += [2] mengubah list di tempat (alias ikut berubah), sedangkan r = r + [2] membuat list baru.
  • Iterasi. Objek iterabel menghasilkan iterator lewat iter(); for memanggil next() sampai StopIteration. Generator (yield) menghasilkan nilai satu per satu dengan memori konstan: sum(len(l) for l in f) memproses berkas 10 GB tanpa memuatnya. Comprehension ([x*x for x in xs if x > 0]) lebih ringkas dan umumnya lebih cepat daripada loop append.
  • Struktur program. Modul adalah berkas .py; if __name__ == "__main__": menjalankan blok hanya bila berkas dijalankan langsung, bukan saat diimpor. with open(f) as h: (context manager) menjamin berkas ditutup walau terjadi galat. @dataclass membuat kelas data ringkas; argparse membuat antarmuka baris perintah; venv memisahkan dependensi per proyek.
  • Angka. int berukuran tak terbatas (berguna untuk hash dan bilangan besar), float adalah IEEE 754 biner 64-bit (M03a): 0.1 + 0.2 != 0.3, bandingkan dengan math.isclose.

4.2 Struktur data bawaan dan biayanya

list adalah array dinamis: elemen berurutan, akses indeks O(1), append amortized O(1) (kapasitas bertumbuh geometris sehingga penyalinan jarang), tetapi insert(0, x), x in list, dan remove adalah O(n). tuple adalah list immutable (bisa jadi kunci dict). dict dan set adalah tabel hash: kunci diubah menjadi indeks lewat hash(k); pencarian, penyisipan, dan penghapusan rata-rata O(1), kasus terburuk O(n) bila banyak kunci bertabrakan. Kunci harus hashable (immutable dan konsisten dengan ==); sejak Python 3.7 dict mempertahankan urutan penyisipan. deque (collections) punya appendleft dan popleft O(1), cocok untuk antrean BFS. heapq mengelola heap biner di atas list: heappush dan heappop O(log n), elemen terkecil di depan; dasar antrean prioritas. bisect mencari di list terurut dalam O(log n).

4.3 Kompleksitas: Big-O, amortized, dan rekurensi

Untuk fungsi f, g dari bilangan asli ke bilangan non-negatif, f(n) = O(g(n)) bila ada konstanta c > 0 dan n0 sehingga f(n) ≤ c · g(n) untuk semua n ≥ n0. Ω adalah batas bawah analog, dan Θ berarti O dan Ω sekaligus. Big-O menyembunyikan konstanta dan suku yang lebih kecil; untuk perbandingan nyata, hitung operasi (seperti di visualisasi 2) atau ukur waktu.

f(n)=O(g(n))⇔∃c>0,∃n0:∀n≥n0,f(n)≤cg(n)f(n) = O(g(n)) jika ada c > 0 dan n0 sehingga untuk semua n >= n0, f(n) <= c g(n)

Amortized. Biaya rata-rata per operasi pada urutan terburuk operasi, bukan rata-rata acak. append pada list: bila kapasitas digandakan saat penuh, n operasi menyalin total kurang dari 2n elemen, jadi tiap append amortized O(1) walau sesekali satu operasi mahal.

Rekurensi pembagi-dan-gabung. Merge sort membagi dua, mengurutkan masing-masing, lalu menggabung dengan paling banyak n − 1 perbandingan: T(n) = 2T(n/2) + n. Pohon rekursi punya log2 n tingkat dan tiap tingkat menyumbang sekitar n kerja, jadi T(n) = Θ(n log n). Untuk T(n) = 2T(n/2) + n² tingkat teratas mendominasi dan hasilnya Θ(n²).

4.4 Pengurutan

  • Insertion sort: menyisipkan elemen ke bagian kiri yang sudah terurut. Terburuk (terbalik) n(n − 1)/2 perbandingan, terbaik (sudah terurut) n − 1, dan efisien untuk data hampir terurut atau kecil.
  • Merge sort: Θ(n log n) pada semua kasus, stabil (elemen sama menjaga urutan), butuh memori tambahan O(n). sorted() dan list.sort() Python memakai Timsort: gabungan merge sort dan insertion sort yang memanfaatkan run terurut sehingga data hampir terurut hampir linear, dan stabil.
  • Quick sort: pilih pivot, partisi, urut dua sisi. Rata-rata Θ(n log n), tetapi bila pivot selalu ekstrem (pivot terakhir pada data yang sudah terurut) partisi tak seimbang dan kasusnya Θ(n²). Perbaikan: pivot acak atau median-dari-tiga.
  • Batas bawah. Pohon keputusan untuk mengurutkan n elemen punya n! daun, jadi tingginya (jumlah perbandingan terburuk) paling sedikit ⌈log2 n!⌉ = Ω(n log n). Contoh: 8 elemen butuh ≥ 16 perbandingan, 10 elemen butuh ≥ 22. Merge sort mencapai batas ini secara asimtotik.

4.5 Graf, algoritma graf, dan kaitannya dengan EDA

Graf G = (V, E) berisi simpul dan sisi. Representasi daftar adjacency (dict simpul → daftar tetangga) memakai ruang O(V + E) dan cocok untuk graf jarang seperti netlist; matriks adjacency memakai O(V²). Netlist digital adalah graf berarah: simpul = gerbang atau port, sisi = kabel dari driver ke penerima.

  • BFS (antrean) menjelajah per lapisan dan memberi jarak terpendek pada graf tak berbobot dalam O(V + E). Dipakai untuk kerucut fanout dan routing labirin Lee pada grid.
  • DFS (tumpukan atau rekursi) menjelajah sedalam mungkin; dasar deteksi siklus dan komponen terhubung.
  • Urutan topologis (algoritma Kahn): ulang ambil simpul berderajat-masuk 0, hapus sisi keluarnya. Ada urutan topologis bila dan hanya bila graf tak bersiklus (DAG); simpul yang tersisa menandai loop kombinasional. Levelization netlist adalah urutan ini.
  • Jalur terpanjang pada DAG dihitung dengan DP sepanjang urutan topologis: arrival(v) = maxu∈fanin(v) arrival(u) + d(v), dalam waktu O(V + E). Itulah inti static timing analysis: slack pada output = waktu diminta (required) − arrival, dan jalur kritis adalah jalur dengan slack terkecil.
  • Dijkstra mencari jalur terpendek dari satu sumber pada graf berbobot non-negatif dengan antrean prioritas (heap): O((V + E) log V). A* menambahkan heuristik h(v) yang tak melebihi jarak sebenarnya (jarak Manhattan di grid) sehingga menjelajah jauh lebih sedikit sel dan tetap optimal.
  • Union-find (himpunan lepas) memelihara partisi dengan find dan union hampir konstan (dengan penyatuan menurut ukuran dan kompresi jalur); dasar algoritma Kruskal untuk pohon rentang minimum dan pengelompokan net.

4.6 Rekursi, memoization, dan dynamic programming

Rekursi menyelesaikan masalah lewat masalah yang lebih kecil. fib(n) = fib(n−1) + fib(n−2) secara naif menghitung ulang submasalah yang sama dan butuh jumlah panggilan eksponensial (242.785 panggilan untuk n = 25). Memoization menyimpan hasil submasalah (functools.lru_cache), sehingga tiap nilai dihitung sekali: 26 panggilan. Bila submasalah tumpang tindih dan solusi optimal tersusun dari solusi optimal submasalah, itu dynamic programming. Contoh: panjang longest common subsequence (LCS) dua urutan dengan tabel (|a|+1) × (|b|+1) dalam waktu O(|a| · |b|); alat diff berbasis gagasan ini. Batas rekursi Python (sekitar 1000 bingkai) berarti rekursi dalam sebaiknya diubah menjadi iterasi dengan tumpukan eksplisit (seperti quick di lab).

4.7 Tcl: dua belas aturan dan pola skrip EDA

Sintaks inti Tcl hanya dua belas aturan (disebut dodecalogue). Rangkumannya yang dipakai sehari-hari:

  1. Skrip adalah deretan perintah dipisah baris baru atau ;. Kata pertama adalah nama perintah, sisanya argumen.
  2. Kata dipisah spasi. Setiap argumen adalah string; Tcl tidak punya tipe tersendiri untuk angka atau list (hanya cara menafsirkan string).
  3. Kata diawali " dipanggang sampai " berikutnya: spasi menjadi bagian kata, dan substitusi berlaku. Kata diawali { berakhir di } yang seimbang: tidak ada substitusi.
  4. [perintah] diganti dengan hasil perintah itu (substitusi perintah). $nama diganti nilai variabel. \x adalah escape (\n, \$, dan \+spasi).
  5. Substitusi terjadi sekali pada tiap kata, dari kiri ke kanan, dan hasilnya tidak dipindai ulang; hasil substitusi tidak dipecah lagi menjadi beberapa kata (nilai ani budi tetap satu kata, tidak seperti di shell).
  6. {*}$lst (expansion) menyebar list menjadi kata-kata terpisah.

Karena itu expr {$x + 1} menerima teks $x + 1 dan expr sendiri yang mengganti $x (lebih cepat karena bisa dikompilasi, dan aman dari injeksi); if {$x > 3} { ... } pun selalu pakai kurung kurawal. Perintah yang kamu butuhkan: set, incr, expr, if/elseif/else, for, foreach, while, proc, return, list, lindex, llength, lappend, lsort, lrange, join, split, dict (create, set, get, lappend, keys), string, format, regexp, open/gets/close, uplevel, upvar.

Tcl di alat EDA. Alat memakai Tcl sebagai bahasa perintah: berkas constraint SDC (create_clock -period 2.0 [get_ports clk]) adalah skrip Tcl dengan perintah tambahan; get_cells, get_ports, dan get_nets mengembalikan koleksi (objek yang dikelola alat, bukan list string biasa, sehingga perlu foreach_in_collection di alat komersial), sementara OpenROAD memakai list Tcl. Pola umum: loop atas objek desain, filter lewat atribut, cetak laporan; pola yang sama dengan logreport.py, dan di lab kamu mengerjakan keduanya sampai output identik.

Jebakan khas Tcl. (1) Memakai expr $a + $b tanpa kurung kurawal: kata hasil bisa mengandung spasi atau karakter khusus yang ditafsir ulang. (2) Menulis list sebagai string dengan "a b {c d}" lalu salah menghitung elemen; bangun list dengan list atau lappend. (3) Mengira " dan { sama: hanya yang pertama melakukan substitusi. (4) Variabel lokal di proc tidak terlihat dari luar dan sebaliknya; gunakan global, upvar, atau argumen.

4.8 Menguji kode algoritma

Algoritma mudah salah di kasus tepi (list kosong, elemen kembar, graf bersiklus). Pola uji yang kuat: bandingkan dengan acuan yang jelas benar pada input acak (sorting versus sorted, Dijkstra versus Floyd–Warshall pada graf kecil), dan periksa properti (urutan topologis menaruh setiap fanin sebelum gerbangnya; fungsi tidak mengubah input). test_algos.py di lab melakukan keduanya dengan unittest.

Penjelasan berlapis

1. Python dan model data

Python adalah bahasa pemrograman yang mudah dibaca. Variabel menunjuk ke data; bila dua variabel menunjuk ke list yang sama, mengubah satu mengubah yang lain. Gunakan list untuk urutan dan dict untuk pasangan kunci-nilai, dan jalankan skrip dengan python3 nama.py.

Ingat aturan: penugasan menyalin referensi, bukan objek. Pakai copy.deepcopy untuk struktur bersarang, None sebagai nilai awal argumen mutable, generator untuk data besar, dan with untuk berkas. Pilih dict/set untuk pencarian, deque untuk antrean, dan heapq untuk antrean prioritas.

CPython menghitung referensi tiap objek dan membersihkan siklus dengan pengumpul sampah generasional; id adalah alamat objek. Dict memakai open addressing dengan urutan probe yang dipengaruhi bit hash dan menyimpan entri dalam array padat terurut penyisipan; hash string diacak per proses (PYTHONHASHSEED) untuk mencegah serangan tabrakan. Timsort mendeteksi run dan memakai galloping; GIL membatasi paralelisme thread untuk kode Python murni sehingga beban CPU memakai multiprocessing.

2. Kompleksitas, struktur data, dan algoritma graf

Cara membandingkan algoritma: seberapa banyak langkah bila datanya 10 kali lebih banyak? Pencarian linear jadi 10 kali lebih lama, pencarian biner hanya sedikit lebih lama, dan algoritma kuadratik jadi 100 kali lebih lama. Graf adalah titik-titik yang dihubungkan garis; BFS menjelajah per lapis, dan Dijkstra mencari jalan terpendek.

Hitung dulu, ukur kemudian: perkirakan kompleksitas, uji dengan data nyata. Pilih representasi graf adjacency list, tulis BFS dengan deque dan Dijkstra dengan heapq (lewati entri usang), dan pakai urutan topologis untuk menghitung arrival time. Waspadai konstanta dan memori: O(n log n) dengan konstanta besar bisa kalah pada n kecil.

Analisis amortized (metode potensial) menjelaskan list dinamis dan union-find (O(α(n)) per operasi). Dijkstra dengan Fibonacci heap mencapai O(E + V log V) tetapi konstantanya jarang menguntungkan. STA nyata memakai propagasi arrival dan required time dua arah, banyak corner, dan model tunda bergantung slew; algoritmanya tetap relaksasi pada DAG. Pada skala miliaran simpul, lokalitas cache dan paralelisme (levelization menghasilkan antrean independen per level) lebih menentukan daripada Big-O.

3. Tcl

Tcl adalah bahasa skrip yang dipakai alat desain chip. Semuanya berupa teks. set x 5 menyimpan nilai, $x memakainya, [...] menjalankan perintah dan memakai hasilnya, dan {...} menjaga teks apa adanya.

Selalu tulis expr {...} dan if {...} dengan kurung kurawal; bangun list dengan list/lappend; gunakan dict untuk data berstruktur dan regexp -all -inline untuk parsing. Pahami perbedaan " dan {, dan pakai {*} saat meneruskan list sebagai argumen.

Tcl 8 mengompilasi skrip ke bytecode dan menyimpan "dual-ported object" (nilai string dengan representasi internal int, list, atau dict yang di-cache); karena itu list besar dalam foreach tetap efisien selama tidak ditafsir ulang sebagai string. Substitusi ganda (eval, uplevel) adalah sumber bug dan injeksi: bangun perintah dengan list agar kutip aman. Command trace, namespace, dan TclOO mendasari alat besar.

2. Berapa perbandingan yang dibutuhkan tiga algoritma pengurutan?

Tiap Maju menggandakan n (4, 8, ..., 1024). Satu perbandingan = satu pemeriksaan a[j] > key (insertion), l[i] <= r[j] (merge, top-down), atau a[j] < pivot (quick, pivot elemen terakhir, partisi Lomuto, tumpukan eksplisit). Kunci = bilangan 0–999 sehingga ada kembar. Identik dengan sort_counts.py. Sumbu: log2 n lawan log10 jumlah perbandingan; garis lurus dengan kemiringan 1 berarti linear, 2 berarti kuadratik.

Pilih data sudah terurut naik dan maju sampai n = 1024. Algoritma mana yang kini paling banyak perbandingan, dan siapa yang justru hanya butuh sekitar n?

  • Quick sort (339.797) paling banyak; insertion hanya 1.023
  • Merge sort paling banyak; quick hanya 1.023
  • Insertion sort paling banyak (sekitar 523.000)
  • Ketiganya sama karena datanya sudah urut

Pada data terurut, pivot terakhir selalu elemen terbesar sehingga partisi hanya mengecilkan masalah satu elemen: perbandingan Θ(n²) (339.797; untuk 1024 kunci yang semuanya berbeda hasilnya tepat 1024 × 1023 / 2 = 523.776, dan lebih kecil di sini karena kunci kembar membuat satu partisi menyingkirkan beberapa elemen sekaligus). Insertion sort justru terbaik di sini: tiap elemen hanya dibandingkan sekali dengan tetangganya, total n − 1 = 1.023. Merge sort tetap 5.120 karena tidak peduli urutan awal. Pelajarannya: kasus terburuk quicksort ada pada input yang tampak "mudah".

3. Static timing analysis mini: arrival time pada DAG gerbang

graf gerbang (garis ungu tebal = jalur kritis, terisi = sedang diproses, tepi hijau = selesai; angka = arrival time)
Graf sama dengan sta_dag.py: input A, B, C (arrival 0); G1 (tunda 2) ← A, B; G2 (3) ← B, C; G3 (2) ← G1, G2; G4 (1) ← G2; G5 (4) ← G3, G4; G6 (2) ← G4, C; output G5 dan G6. Tiap Maju memproses satu simpul dalam urutan topologis Kahn (derajat-masuk 0, nama terkecil lebih dulu): arrival = max(arrival fanin) + tunda. Bila dua fanin sama besar, jalur kritis memilih nama terbesar (aturan seri di kode). Slack = T − arrival output; negatif berarti melanggar timing.

Biarkan T = 9, pilih G2 diperlambat (+3), dan jalankan sampai selesai. Apa slack terburuk dan jalur kritisnya?

  • Slack −3 pada G5; jalur kritis C → G2 → G3 → G5
  • Slack 0 pada G5; jalur kritis tidak berubah dan masih aman
  • Slack −3 pada G6; jalur kritis C → G2 → G4 → G6
  • Slack −1 pada G5; jalur kritis A → G1 → G3 → G5

G2 yang lambat menaikkan arrival G2 dari 3 menjadi 6, lalu G3 = 8, G4 = 7, dan G5 = max(8, 7) + 4 = 12. Slack G5 = 9 − 12 = −3 (melanggar). G6 = max(7, 0) + 2 = 9 sehingga slack 0. Jalur kritis adalah rantai penentu max di tiap simpul: C → G2 → G3 → G5 (pada G2 kedua fanin B dan C tiba di 0, aturan seri memilih C). Naikkan T ke 12 dan slack G5 kembali 0, persis hasil sta_dag.py.

#!/usr/bin/env python3
"""sort_counts.py: hitung perbandingan elemen insertion, merge, dan quick sort pada n kunci."""
def lcg(n, seed=12345):
    x, out = seed, []
    for _ in range(n):
        x = x * 48271 % 2147483647      # Park-Miller; muat di float64 sehingga identik dengan JavaScript
        out.append(x % 1000)
    return out

def insertion(a):
    a, cmp = a[:], 0
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0:
            cmp += 1
            if a[j] > key:
                a[j + 1] = a[j]; j -= 1
            else:
                break
        a[j + 1] = key
    return a, cmp

def merge_sort(a):
    cmp = 0
    def ms(x):
        nonlocal cmp
        if len(x) <= 1:
            return x
        m = len(x) // 2
        l, r = ms(x[:m]), ms(x[m:])
        out, i, j = [], 0, 0
        while i < len(l) and j < len(r):
            cmp += 1
            if l[i] <= r[j]:
                out.append(l[i]); i += 1
            else:
                out.append(r[j]); j += 1
        return out + l[i:] + r[j:]
    return ms(a[:]), cmp

def quick(a):
    a, cmp, st = a[:], 0, [(0, len(a) - 1)]
    while st:
        lo, hi = st.pop()
        if lo >= hi:
            continue
        piv, i = a[hi], lo
        for j in range(lo, hi):
            cmp += 1
            if a[j] < piv:
                a[i], a[j] = a[j], a[i]; i += 1
        a[i], a[hi] = a[hi], a[i]
        st.append((lo, i - 1)); st.append((i + 1, hi))
    return a, cmp

def data(kind, n):
    d = lcg(n)
    return sorted(d) if kind == "sorted" else (sorted(d, reverse=True) if kind == "reverse" else d)

if __name__ == "__main__":
    for kind in ("random", "sorted", "reverse"):
        print(kind)
        for n in (4, 8, 16, 32, 64, 128, 256, 512, 1024):
            d = data(kind, n)
            r = [f(d) for f in (insertion, merge_sort, quick)]
            assert all(x[0] == sorted(d) for x in r)
            print(f"  n={n:5d} insertion={r[0][1]:8d} merge={r[1][1]:6d} quick={r[2][1]:8d}")

#!/usr/bin/env python3
"""sta_dag.py: waktu tiba terlama (arrival time) pada DAG gerbang, urutan topologis Kahn."""
from collections import defaultdict
import heapq

GATES = {            # nama: (tunda, [fanin])
    "G1": (2, ["A", "B"]), "G2": (3, ["B", "C"]), "G3": (2, ["G1", "G2"]),
    "G4": (1, ["G2"]),     "G5": (4, ["G3", "G4"]), "G6": (2, ["G4", "C"]),
}
INPUTS = ["A", "B", "C"]
OUTPUTS = ["G5", "G6"]

def analyze(gates, period, slow=None, extra=0):
    delay = {g: d + (extra if g == slow else 0) for g, (d, _) in gates.items()}
    fan = defaultdict(list); indeg = {g: len(f) for g, (_, f) in gates.items()}
    for g, (_, fi) in gates.items():
        for s in fi: fan[s].append(g)
    indeg.update({i: 0 for i in INPUTS})
    ready = [n for n in indeg if indeg[n] == 0]; heapq.heapify(ready)   # urutan deterministik
    arr, via, order = {i: 0 for i in INPUTS}, {}, []
    while ready:
        n = heapq.heappop(ready); order.append(n)
        if n in gates:
            fi = gates[n][1]
            best = max(fi, key=lambda s: (arr[s], s))                  # seri: pilih nama terbesar
            arr[n] = arr[best] + delay[n]; via[n] = best
        for m in fan[n]:
            indeg[m] -= 1
            if indeg[m] == 0: heapq.heappush(ready, m)
    slack = {o: period - arr[o] for o in OUTPUTS}
    worst = min(OUTPUTS, key=lambda o: (slack[o], o))
    path, n = [worst], worst
    while n in via: n = via[n]; path.append(n)
    return order, arr, slack, path[::-1]

if __name__ == "__main__":
    for period, slow in ((9, None), (9, "G2"), (12, "G2")):
        order, arr, slack, path = analyze(GATES, period, slow, 3)
        print(f"T={period} lambat={slow}: order={' '.join(order)}")
        print("  arrival:", " ".join(f"{k}={arr[k]}" for k in sorted(arr)))
        print("  slack  :", " ".join(f"{k}={v}" for k, v in slack.items()), "| jalur kritis:", "->".join(path))

#!/usr/bin/env python3
"""dp_demo.py: rekursi eksponensial menjadi linear lewat memoization; LCS (dasar alat diff) dengan tabel DP."""
from functools import lru_cache

calls = 0
def fib_naif(n):
    global calls
    calls += 1
    return n if n < 2 else fib_naif(n - 1) + fib_naif(n - 2)

memo_calls = 0
@lru_cache(maxsize=None)
def fib_memo(n):
    global memo_calls
    memo_calls += 1
    return n if n < 2 else fib_memo(n - 1) + fib_memo(n - 2)

def lcs(a, b):
    """panjang subsequence persekutuan terpanjang; tabel (len(a)+1) x (len(b)+1), waktu O(len(a) * len(b))."""
    t = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i, x in enumerate(a, 1):
        for j, y in enumerate(b, 1):
            t[i][j] = t[i - 1][j - 1] + 1 if x == y else max(t[i - 1][j], t[i][j - 1])
    return t[-1][-1]

if __name__ == "__main__":
    for n in (10, 20, 25):
        calls = 0
        print(f"fib({n}) = {fib_naif(n)} dengan {calls} panggilan")
    fib_memo.cache_clear(); memo_calls = 0
    print(f"fib(25) memo = {fib_memo(25)} dengan {memo_calls} panggilan")
    print("lcs('ABCBDAB', 'BDCABA') =", lcs("ABCBDAB", "BDCABA"))

#!/usr/bin/env python3
"""logreport.py: baca laporan timing, kelompokkan per group, tulis CSV. Memakai regex, dataclass, defaultdict."""
import csv, re, sys
from collections import defaultdict
from dataclasses import dataclass

PAT = re.compile(r"path=(?P<id>\d+) start=(?P<start>\S+) end=(?P<end>\S+) group=(?P<group>\w+) slack=(?P<slack>-?\d+\.\d+) cells=(?P<cells>\d+)")

@dataclass(frozen=True)
class Path:
    id: int; start: str; end: str; group: str; slack: float; cells: int

def parse(lines):
    for n, line in enumerate(lines, 1):
        if not line.strip() or line.startswith("#"):
            continue
        m = PAT.fullmatch(line.strip())
        if not m:
            raise ValueError(f"baris {n} tidak dikenal: {line!r}")
        d = m.groupdict()
        yield Path(int(d["id"]), d["start"], d["end"], d["group"], float(d["slack"]), int(d["cells"]))

def summary(paths):
    by = defaultdict(list)
    for p in paths:
        by[p.group].append(p)
    return {g: (min(x.slack for x in ps), sum(1 for x in ps if x.slack < 0), len(ps)) for g, ps in sorted(by.items())}

if __name__ == "__main__":
    with open(sys.argv[1] if len(sys.argv) > 1 else "sample_timing.rpt") as f:
        paths = list(parse(f))
    print("group  WNS    jumlah_violasi  jumlah_path")
    for g, (wns, nv, n) in summary(paths).items():
        print(f"{g:5s} {wns:6.2f} {nv:8d} {n:14d}")
    worst = sorted(paths, key=lambda p: p.slack)[:3]
    print("3 terburuk:", ", ".join(f"{p.id}({p.slack:+.2f})" for p in worst))
    w = csv.writer(sys.stdout, lineterminator="\n")
    w.writerow(["id", "start", "end", "slack"])
    for p in worst:
        w.writerow([p.id, p.start, p.end, f"{p.slack:.2f}"])

    set paths {}
    set fh [open $fname r]
    while {[gets $fh line] >= 0} {
        if {[string trim $line] eq "" || [string index $line 0] eq "#"} continue
        set d [dict create]
        foreach {all k v} [regexp -all -inline {(\w+)=(\S+)} $line] { dict set d $k $v }
        lappend paths $d

    return $paths
}

#!/usr/bin/env python3
"""netlist_graph.py: netlist kecil sebagai graf berarah: levelization, kerucut fanout (BFS), deteksi loop kombinasional."""
import re
from collections import deque, defaultdict

NETLIST = """
n1 = AND(a, b)
n2 = OR(n1, c)
n3 = NOT(n2)
y  = XOR(n3, n1)
z  = AND(n2, d)
"""
LOOP = NETLIST + "p = AND(q, a)\nq = OR(p, b)\n"

def parse(text):
    g = {}
    for line in text.strip().splitlines():
        m = re.fullmatch(r"\s*(\w+)\s*=\s*(\w+)\(([^)]*)\)\s*", line)
        if not m:
            raise ValueError(line)
        g[m.group(1)] = (m.group(2), [s.strip() for s in m.group(3).split(",")])
    return g

def levelize(g):
    """level(input)=0; level(gerbang)=1+max(level fanin). Mengembalikan (level, node tersisa jika ada siklus)."""
    fan, indeg = defaultdict(list), {}
    for n, (_, fi) in g.items():
        indeg[n] = len(fi)
        for s in fi:
            fan[s].append(n)
    ins = {s for _, fi in g.values() for s in fi if s not in g}
    level = {i: 0 for i in ins}
    for n in g:                                  # fanin yang berupa input primer tidak menambah derajat
        indeg[n] = sum(1 for s in g[n][1] if s in g)
    q = deque(sorted(n for n in g if indeg[n] == 0))
    done = 0
    while q:
        n = q.popleft(); done += 1
        level[n] = 1 + max(level[s] for s in g[n][1])
        for m in sorted(fan[n]):
            if m in g:
                indeg[m] -= 1
                if indeg[m] == 0:
                    q.append(m)
    return level, sorted(n for n in g if n not in level)

def fanout_cone(g, start):
    fan = defaultdict(list)
    for n, (_, fi) in g.items():
        for s in fi:
            fan[s].append(n)
    seen, q = {start}, deque([start])
    while q:
        n = q.popleft()
        for m in sorted(fan[n]):
            if m not in seen:
                seen.add(m); q.append(m)
    return sorted(seen - {start})

if __name__ == "__main__":
    g = parse(NETLIST)
    level, stuck = levelize(g)
    print("level:", " ".join(f"{n}={level[n]}" for n in sorted(level, key=lambda k: (level[k], k))))
    print("kerucut fanout dari n1:", fanout_cone(g, "n1"), "| dari c:", fanout_cone(g, "c"))
    level, stuck = levelize(parse(LOOP))
    print("loop kombinasional pada:", stuck)

#!/usr/bin/env python3
"""maze_route.py: routing labirin (algoritma Lee = BFS) vs A* pada grid dengan halangan."""
import heapq
from collections import deque

GRID = [
    "S.........",
    "..........",
    "....####..",
    "....#.....",
    "....#..#..",
    "....#..#..",
    "..###..#..",
    "..........",
    "..........",
    ".........T",
]
def find(ch):
    for r, row in enumerate(GRID):
        if ch in row:
            return r, row.index(ch)

def nbrs(r, c):
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        rr, cc = r + dr, c + dc
        if 0 <= rr < len(GRID) and 0 <= cc < len(GRID[0]) and GRID[rr][cc] != "#":
            yield rr, cc

def lee(s, t):
    dist, q, popped = {s: 0}, deque([s]), 0
    while q:
        u = q.popleft(); popped += 1
        if u == t:
            return dist[u], popped
        for v in nbrs(*u):
            if v not in dist:
                dist[v] = dist[u] + 1; q.append(v)
    return None, popped

def astar(s, t):
    h = lambda u: abs(u[0] - t[0]) + abs(u[1] - t[1])
    best, pq, popped = {s: 0}, [(h(s), 0, s)], 0   # (f, -g, sel): seri f dimenangkan g terbesar
    while pq:
        f, ng, u = heapq.heappop(pq); g = -ng
        if g > best[u]:
            continue
        popped += 1
        if u == t:
            return g, popped
        for v in nbrs(*u):
            if g + 1 < best.get(v, 1 << 30):
                best[v] = g + 1; heapq.heappush(pq, (g + 1 + h(v), -(g + 1), v))
    return None, popped

if __name__ == "__main__":
    s, t = find("S"), find("T")
    print("Lee   : panjang %s, sel diperluas %d" % lee(s, t))
    print("A*    : panjang %s, sel diperluas %d" % astar(s, t))

#!/usr/bin/env python3
"""graph_algos.py: Dijkstra (heap) dan union-find (Kruskal, pohon rentang minimum)."""
import heapq

def dijkstra(adj, src):
    dist, pq = {src: 0}, [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float("inf")):
            continue                              # entri usang
        for v, w in adj.get(u, ()):
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd; heapq.heappush(pq, (nd, v))
    return dist

class UnionFind:
    def __init__(self, items):
        self.p = {x: x for x in items}; self.sz = {x: 1 for x in items}
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]          # path halving
            x = self.p[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a; self.sz[a] += self.sz[b]
        return True

def kruskal(nodes, edges):
    uf, mst, total = UnionFind(nodes), [], 0
    for w, a, b in sorted(edges):
        if uf.union(a, b):
            mst.append((a, b, w)); total += w
    return mst, total

if __name__ == "__main__":
    adj = {"S": [("A", 4), ("B", 1)], "B": [("A", 2), ("C", 6)], "A": [("C", 3)], "C": []}
    print("dijkstra dari S:", dict(sorted(dijkstra(adj, "S").items())))
    edges = [(4, "a", "b"), (1, "a", "c"), (3, "b", "c"), (2, "b", "d"), (5, "c", "d")]

Tingkat 3 Menganalisis

3.1 Buktikan bahwa merge sort top-down pada n = 2k kunci berbeda melakukan paling sedikit (n/2) log₂ n dan paling banyak n log₂ n − n + 1 perbandingan, dan cocokkan dengan n = 1024.

Solusi 3.1

Menggabungkan dua list terurut berukuran m membutuhkan antara m perbandingan (semua elemen kiri lebih dulu habis) dan 2m − 1 (bergantian sampai satu elemen terakhir). Pada tingkat dengan blok hasil berukuran 2m ada n/(2m) penggabungan: batas bawah n/2 per tingkat, batas atas n − n/(2m) per tingkat. Ada k = log₂ n tingkat (m = 1, 2, 4, ..., n/2). Batas bawah: k · n/2 = (n/2) log₂ n. Batas atas: Σ (n − n/(2m)) = kn − n(1/2 + 1/4 + ... + 1/n) = kn − n(1 − 1/n) = n log₂ n − n + 1. Untuk n = 1024: 5.120 ≤ C ≤ 9.217. Terukur: 5.120 pada data terurut (batas bawah), 8.938 pada data acak, dan 5.332 pada data terbalik (ada kunci kembar). Semuanya di dalam rentang.

3.2 Buktikan bahwa quicksort dengan pivot elemen terakhir pada n kunci berbeda yang sudah terurut melakukan tepat n(n − 1)/2 perbandingan, dan jelaskan mengapa angka terukur 339.797 (untuk 1024 kunci dengan kembar) lebih kecil.

Solusi 3.2

Pivot terakhir adalah elemen terbesar. Partisi atas m elemen membandingkan m − 1 elemen dengan pivot, semuanya lebih kecil, sehingga bagian kiri berukuran m − 1 dan bagian kanan kosong. Maka T(m) = T(m − 1) + (m − 1) dengan T(1) = 0, dan T(n) = Σm=2n (m − 1) = n(n − 1)/2 = 523.776 untuk n = 1024 (juga terukur pada list(range(1024))). Pada kunci 0–999 hanya 657 nilai berbeda: elemen yang sama dengan pivot tidak lebih kecil darinya, sehingga satu partisi bisa menyisihkan beberapa elemen sekaligus dan rantai pembagian lebih pendek; tetap kuadratik, tetapi dengan konstanta lebih kecil.

3.3 Buktikan bahwa algoritma Kahn meninggalkan simpul yang belum diproses jika dan hanya jika graf punya siklus.

Solusi 3.3

(⇒) Misalkan setelah algoritma berhenti masih ada simpul. Tiap simpul sisa punya derajat-masuk ≥ 1 yang berasal dari simpul sisa (jika tidak, simpul itu sudah masuk antrean dan diproses). Mulai dari satu simpul sisa dan telusuri satu pendahulu sisa secara berulang. Jumlah simpul hingga, jadi penelusuran akhirnya mengunjungi simpul yang sama dua kali, dan itulah siklus. (⇐) Bila ada siklus, simpul pertama di siklus yang akan masuk antrean membutuhkan pendahulunya di siklus sudah diproses lebih dulu, kontradiksi; maka tak satu pun simpul siklus pernah mencapai derajat-masuk 0 dan semuanya tersisa. Itu sebabnya levelize mengembalikan ['p', 'q'] untuk LOOP. Waktunya O(V + E).

Pertanyaan interview

"Mengapa argumen bawaan [] berbahaya?"

Kerangka jawaban: Nilai bawaan dievaluasi sekali saat def dijalankan, bukan tiap pemanggilan; list yang sama dipakai terus dan mengumpulkan sisa pemanggilan sebelumnya. Perbaikan: None sebagai penanda lalu buat list baru di dalam fungsi.

"Urutkan 1 juta bilangan: algoritma apa dan mengapa? Kapan quicksort buruk?"

Kerangka jawaban: Pakai sorted (Timsort, stabil, O(n log n), memanfaatkan runs yang sudah terurut). Quicksort rata-rata cepat dan hemat memori tetapi kasus terburuk O(n²) bila pivot buruk (pivot terakhir pada data terurut: 339.797 perbandingan pada 1024 data). Mitigasi: pivot acak atau median-dari-tiga, atau introsort. Merge sort stabil dan prediktabel tetapi butuh memori tambahan O(n).

"Jelaskan static timing analysis sebagai masalah graf."

Required time diperoleh dari periode clock secara mundur; slack = required − arrival; slack negatif melanggar. Jalur kritis = rantai yang menentukan maksimum. Catat: loop kombinasional menggagalkan urutan topologis, jadi harus diputus; alat nyata menambah derating, banyak corner, dan clock pessimism.

"Kapan BFS, Dijkstra, dan A* dipakai?"

Kerangka jawaban: BFS untuk jarak pada graf tak berbobot (algoritma Lee pada routing labirin). Dijkstra untuk bobot non-negatif, O((V + E) log V) dengan heap. A* menambah heuristik admissible (jarak Manhattan pada grid) sehingga memperluas lebih sedikit sel dengan hasil optimal yang sama (19 lawan 87 sel pada contoh maze_route.py, panjang jalur sama-sama 18). Bobot negatif: Bellman-Ford.

"Apa yang dilakukan Tcl pada baris puts $x$y dan mengapa expr {...} memakai kurung kurawal?"

Kerangka jawaban: Tcl memecah baris menjadi kata, lalu mengganti $, [ ], dan \ sekali per kata; $x$y menjadi satu kata gabungan. Kurung kurawal mencegah substitusi oleh Tcl sehingga expr menerima teks mentah, mengganti sendiri, dan bisa mengompilasi ekspresi ke bytecode (lebih cepat) serta aman dari injeksi lewat nilai variabel.

  • Python: nama menunjuk objek; penugasan menyalin referensi; mutable lawan immutable; salinan dangkal berbagi isi bersarang, deepcopy tidak; jangan pakai argumen bawaan mutable; += pada list mengubah di tempat.

  • Graf: BFS (tak berbobot, Lee), DFS, urutan topologis Kahn (O(V + E), mendeteksi siklus), Dijkstra (bobot non-negatif; O((V + E) log V)), A* (heuristik admissible), Kruskal (pohon rentang minimum).   • Tcl: semua string; pecah kata, lalu substitusi sekali ($, [ ], \); { } mencegah substitusi, " " mengizinkan; expr {...} selalu berkurung; {*} menyebar list; list, dict, foreach, proc.
